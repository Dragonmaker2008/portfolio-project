About Me

I enjoy taking a messy problem, breaking it down logically, and building simple, usable pages for it. Outside of coding, pen-and-ink sketching helps me pay attention to small details and layout.

Projects that I have made so far:

OTP Authentication System

Purpose: Made a user verification flow where a user registers, verifies a one-time code (OTP), logs in, and accesses a protected dashboard.
What I learned: Setting up routes with Express, sending requests from the frontend to the backend, working with OTPs and JWT tokens, and handling basic auth checks.
Tech Stack: Node.js, Express, JWT, JavaScript, HTML, CSS.
How to run locally:
• Start the backend with node server.js on http://localhost:5000 and open the OTP auth HTML page.
• The 6-digit OTP prints in the server terminal so you can test verification, login, and the protected route.
